## [1.0.0] - 2026-05-28
### Added
- Initial release of GS1 Resolver
- React SPA with card-based product display
- AWS CDK infrastructure (DynamoDB, Lambda, API Gateway, CloudFront)
- Cognito authentication for admin panel
- CRUD operations for products
- Custom domain with HTTPS
- 5 sample Swedish grocery products
- Compact design with #3B507D, #0C1122, #FFFFFF color scheme
- Comprehensive nutrition facts display
- Allergen warnings
- Category tags
- Responsive design

### Technical
- TypeScript for CDK and Lambda
- React with TypeScript and Vite
- DynamoDB with PK/SK pattern
- CORS-enabled API
- CloudFront CDN
- Route53 DNS
- ACM SSL certificate
